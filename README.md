# Controle de Medição 

Olá, Tudo bem? Gostaria de uma ajuda! Hoje na empresa temos um processo dentro do setor de qualidade onde nossos colaboradores da linha de operação CNC trazem os ferrolhos de suas células para uma inspeção/medição na máquina tridimensional (Zeiss), para este processo ser feito, é realizado uma inserção de dados em uma painel VBA, onde as informações inseridas no painel são direcionadas diretamente à uma planilha interligada à interface do VBA, lá os inspetores podem observar estas informações e adicioná-las nos relatórios pós a medição estar concluída. Minha ideia é atualizar este processo criando uma interface própria e funcional com um banco de dados próprio, também interligada com uma planilha, a funcionalidade seria a mesma: preencher a interface - informações preenchidas são direcionadas automaticamente para planilha de dados. Andei produzindo alguns exemplares que estarão em anexo, porém sinto que este processo pode ficar mais estilizado e profissional, gostaria que você me ajudasse. Em anexo também deixarei alguns elementos que podem ser remanejados ou ate adicionados, de acordo com sua preferência.
